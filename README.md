# Anshu Rana — Developer Portfolio

A React + JavaScript + Vite portfolio using Tailwind CSS, Framer Motion, Lucide icons, and React Router.

## Run locally

1. Install Node.js 20.19+ (or a current compatible Node.js release).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Run `npm run build` to create a production build.

## Personalize before publishing

- Update `src/data/profile.js` with your verified email address, LinkedIn URL, resume path, dates, and project links.
- Add your resume as `public/resume.pdf` or change `profile.contact.resume` to the correct path.
- Replace placeholder `#` links for projects/achievements only when you have real URLs.
- The contact form uses a `mailto:` fallback. It opens the visitor's email application; it does not send/store messages through a backend.
- Check that descriptions accurately reflect your own contribution and the actual status of each project before publishing.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run lint` — lint source files with Oxlint
- `npm run preview` — preview the production build locally
